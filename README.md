# 🌱 Smart Agriculture — Disease Detection & Yield Prediction

## 📌 Project Overview
Smart Agriculture is a web application built with Artificial Intelligence and Machine Learning to demonstrate plant disease detection and crop yield prediction.

## 🚀 Features
- 🌿 Plant disease detection from leaf images
- 🌾 Crop yield prediction
- 🌦️ Automatic weather data using Open-Meteo
- 💡 Smart recommendations
- 📊 Prediction history and dashboard
- 🔐 User registration and login

## 🛠️ Technologies Used
- Python
- Flask
- TensorFlow / Keras
- Scikit-learn
- Pandas and NumPy
- SQLite
- HTML, CSS and JavaScript
- Open-Meteo API

## ⚙️ How to Run
1. Clone this repository.
2. Install Python 3.12.
3. Create a virtual environment.
4. Install the dependencies using `pip install -r requirements.txt`.
5. Run the application using `python app.py`.
6. Open `http://127.0.0.1:5000` in your browser.

**Important:** The trained disease model file is not included in this repository because of its size. You must add that file separately before running disease detection from a fresh clone.

## ⚠️ Disclaimer
This is an academic demonstration project. The yield model uses synthetic/demo data, and disease predictions are not professionally validated. Do not rely on them as agricultural advice.
